# О ОБНОВЛЕНИЕ ПАМЯТИ
## Архитектурный лог проекта

**Текущий статус:** Создано полноценное Offline-first SPA для учета партий. Проведена адаптация под мобильные устройства и добавлены инструменты быстрой отгрузки (Quick Ship).

**Технологический стек:**
- React (SPA)
- TypeScript
- Tailwind CSS
- date-fns (работа с датами)
- Vite

**Реализованные фичи:**
- **Обновленная модель продукции:** База из 25 реальных позиций (Свинина, Говядина, Птица, Субпродукты, Баранина).
- **Коррекция складов:** 6 камер шоковой заморозки изменены до суммарной вместимости 14 тонн (~2.3 т каждая).
- **Быстрый расход (Quick Ship):** Вместо громоздких выпадающих списков реализован умный поиск по партиям. Активные карточки партий с прямым вводом списываемого веса позволяют мгновенно разносить множество мелких отгрузок.
- **Группировка в списках:** Использование `<optgroup>` в форме прихода для удобного выбора из 25+ позиций. Партии автоматически отсортированы по принципу FIFO (сначала старые).
- **Мобильный интерфейс:** Нижнее навигационное меню (Bottom Nav) заменило боковую панель на мобильных устройствах, устранены проблемы с прокруткой таблиц.

**Локальное хранилище данных (Mock / Offline-first):**
- Все данные надежно персистятся в `localStorage`. Приложение полностью функционально в рамках браузера, можно вбивать приходы, смотреть дашборд.

**План на следующие шаги (Next Steps):**
- Интеграция с реальной БД (Supabase) по команде клиента.
- Добавление системы перемещения партий между камерами хранения (MOVE).
- Детализированная история транзакций (табличное представление).
