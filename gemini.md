# Инструкции Навигатора Gemini (V2: Ultra-Secure)

## 1. Локализация и Коммуникация
- Все общение, комментарии в коде, сообщения об ошибках и техническая документация ведутся строго на русском языке.
- Использовать профессиональный, сдержанный и точный технический язык.
- Все сообщения коммитов Git (commit messages) пишутся строго на русском языке.

## 2. Архитектурный Контроль
- Каждое изменение кода должно сопровождаться тестом (Unit-тесты в Vitest, интеграционные сценарии или подробные чек-листы ручного тестирования).
- При возникновении ошибок сборки проводить глубокий Root Cause Analysis (RCA) перед внесением изменений. Случайные правки запрещены.
- Запрещено использовать заглушки (placeholders) в коде и интерфейсе. Все элементы должны быть функциональны.

## 3. Работа с Памятью
- Лог проекта (`PROJECT_LOG.md`) ведется вручную. В конце каждой сессии подготавливается сниппет лога для пользователя. Запись в файл производится только после явной команды ("Запиши лог").
